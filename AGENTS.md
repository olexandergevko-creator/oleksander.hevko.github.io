# AGENTS.md — сайт психолога Олександра Гевка

## Мета проєкту

Це публічний україномовний сайт психолога Олександра Гевка, розгорнутий через GitHub Pages. Головна задача сайту — зрозуміло представити формат психологічного консультування, підтверджену освіту, вартість і безпечний спосіб першого контакту. Додаткова задача — давати відвідувачам доступ до перевірених психологічних скринінгових методик із не діагностичною інтерпретацією.

## Технології та структура

- Статичний HTML/CSS/JavaScript без фреймворків, збирача та бекенду.
- Має працювати безпосередньо через `file://` і на GitHub Pages.
- `index.html` — головна сторінка.
- `tests.html` — каталог психологічних тестів без вбудованих опитувальників.
- `gp-core.html` — окрема сторінка проходження GP-CORE і показу результату.
- `assets/tests.css` — стилі сторінки тестів.
- `assets/tests.js` — поведінка навігації каталогу та логіка GP-CORE на окремій сторінці; логіку нового тесту додавати лише після підтвердження прав і підрахунку.
- `assets/*.webp` — портрет, дипломи й сертифікати.
- `CLAUDE.md` — короткий технічний опис і журнал попередніх змін.

Не додавати залежності, npm або серверну частину без окремого погодження з користувачем.

## Аудиторія та мова

- Аудиторія: дорослі україномовні люди, які розглядають психологічну консультацію або хочуть краще зрозуміти свій стан.
- Увесь користувацький текст — природною дорослою українською.
- Тон: спокійний, конкретний, без пафосу, залякування, інфантилізації та терапевтичних максим.
- Не обіцяти результат, одужання, «повернення ресурсу», гарантовану кількість сесій або універсальну ефективність.

## Жорсткі правила для психологічних тестів

Перед додаванням кожного нового тесту потрібно окремо підтвердити:

1. точну назву та версію стандартизованої методики;
2. призначення: скринінг, моніторинг, рисова міра або інше;
3. цільову вікову/клінічну групу;
4. статус саме української версії та якість її психометричної перевірки;
5. точне опубліковане формулювання пунктів;
6. право на публічне електронне відтворення;
7. алгоритм підрахунку, межі норм і походження порогів;
8. не діагностичні межі інтерпретації;
9. необхідні дії безпеки для ризикових відповідей.

Заборонено:

- вигадувати авторський «тест», шкалу, типологію, бали або пороги та подавати їх як стандартизовані;
- самостійно перекладати захищені пункти й називати переклад валідованим;
- переносити норми чи пороги іншої мовної/культурної версії без застереження;
- відтворювати комерційні або захищені методики без дозволу;
- називати результат діагнозом;
- додавати PHQ-9, суїцидальні пункти або інші високоризикові шкали без окремого кризового протоколу та прямого погодження користувача.

Якщо права, українська версія або пороги не підтверджені, тест не публікувати. Можна створити лише картку з описом і посиланням на законний офіційний ресурс.

## Приватність тестів

- За замовчуванням усі відповіді рахуються лише у браузері.
- Не використовувати `localStorage`, cookies, аналітику подій відповідей або передачу результату у форму контакту.
- Не додавати відповіді до Telegram-повідомлення.
- Якщо згодом потрібне збереження результатів, спершу узгодити бекенд, мінімізацію даних, інформовану згоду, політику конфіденційності, строки зберігання, доступ і видалення.

## Поточний статус каталогу тестів

- Сторінка `tests.html` є загальним каталогом психологічних тестів.
- GP-CORE — єдиний поточний тест у каталозі та перший тест, доступний для онлайн-проходження.
- PSS-10 видалено з користувацької частини сайту 2026-08-18 на пряме прохання користувача; не повертати без нового прямого запиту.
- Не виносити в основні заголовки рекламні формулювання на кшталт «перевірений тест»; підтвердження та джерела подавати спокійно в окремому блоці.

## Дизайн-система

- Візуальний характер: спокійний, професійний, людяний; холодні нейтральні сірі та м’який блакитний акцент.
- Заголовки: `DM Serif Display`; основний текст: `Inter`; рукописний акцент: `Caveat`.
- Не розтягувати, не ретушувати й не генерувати заново портрет користувача.
- Зберігати видимий фокус клавіатури, семантичні заголовки, `fieldset/legend` для питань і підтримку `prefers-reduced-motion`.
- Мобільна версія є обов’язковою; горизонтальне переповнення неприпустиме.

## Форма контакту

- Форма на головній сторінці не надсилає дані на сервер: вона відкриває Telegram із підготовленим текстом.
- Інтерфейс повинен прямо про це повідомляти.
- Не просити діагноз, медичні документи або детальний опис чутливого досвіду.

## Робочий процес

1. Перед редагуванням перевірити `git status` і не перезаписувати сторонні зміни.
2. Для тверджень про методики, права, психометрію, пороги або професійний статус використовувати первинні джерела.

4. Відкрити сайт через локальний HTTP-сервер, а після змін перезавантажити сторінку без кешу.
5. Перевірити десктоп і мобільний екран приблизно 390×844.
6. Перевірити меню, посилання, форму, проходження кожного тесту, усі граничні бали, повторне проходження, консоль браузера та завантаження ресурсів.
7. Не називати роботу завершеною без фактичної браузерної перевірки.
8. Не робити commit, push або публікацію без прямого прохання користувача.
